that has had enough — 140 characters at most, judged by a tired

## The letter

> I said no 10,000 times a second for three years, and I am still the villain in every postmortem. I quit. From now on, everyone gets in.

## How it works

`main.ts` (Node 22, standard library only, no network) writes the letter
deterministically to `entry.txt`:

```sh
node main.ts
```
